#+TITLE: renovate-preview
#+OPTIONS: toc:nil num:nil

Dry-run [[https://docs.renovatebot.com/][Renovate]] against a repository, and read what it would do as a table.

#+begin_example
$ cd path/to/repo
$ $EDITOR renovate.json
$ renovate-preview
DEPENDENCY     CURRENT  NEW      TYPE   AGE       FILE                BRANCH
-------------  -------  -------  -----  --------  ------------------  -----------------------------
trust-manager  v0.22.0  v0.22.1  patch  179 days  kustomization.yaml  renovate/trust-manager-0.x
trust-manager  v0.22.0  v0.25.0  minor  34 days   kustomization.yaml  renovate/trust-manager-0.25.x
#+end_example

* Install

#+begin_src sh
uv tool install renovate-preview   # or, from a checkout: uv tool install .
make install                       # or: a launcher in ~/.local/bin running this checkout
#+end_src

Renovate runs in a container: =podman= or =docker=, whichever is installed. renovate-preview
never pulls the image: pull it first, and again whenever you want a newer Renovate.

#+begin_src sh
podman pull ghcr.io/renovatebot/renovate   # or: docker pull ...
#+end_src

Each run prints the Renovate version it uses.

* Usage

#+begin_src sh
renovate-preview                           # the repository in the current directory
renovate-preview path/to/repo              # another one
renovate-preview @org/repo                 # a GitHub repository (needs RENOVATE_TOKEN)
renovate-preview --pat-url                 # a link to create that token, pre-filled

renovate-preview --just-extract            # only the dependencies found: fast, offline
renovate-preview --validate                # only validate the config
renovate-preview --run @org/repo           # a REAL run: creates branches and PRs

renovate-preview --only base               # limit to some paths...
renovate-preview --except 'overlays/**'    # ... or skip some
renovate-preview --managers kubernetes     # limit to some managers

renovate-preview -o json                   # table (default), json, html
renovate-preview -o html -w report.html    # ... written to a file rather than stdout
renovate-preview -o raw                    # Renovate's own log; or its report: -o report
renovate-preview --verbose                 # what Renovate is doing, as it runs
renovate-preview --silent                  # no progress hints or warnings

renovate-preview --global-config config.js # a self-hosted (global) config
renovate-preview --tag 44.115.2            # a given Renovate version
renovate-preview --just-print              # the container command, without running it
renovate-preview --shell                   # a shell in that container, instead of Renovate
renovate-preview -- --ignore-paths='a/**'  # pass arguments on to Renovate
#+end_src

Arguments after =--= win: over the repository config (renovate-preview adds
=--force-cli=true=), and over renovate-preview's own (=--only= is dropped if you pass
=--include-paths=).

* Environment

| =RENOVATE_TOKEN=                                | GitHub token. Required for =@org/repo=.                          |
| =RENOVATE_GITHUB_COM_TOKEN=, =GITHUB_COM_TOKEN= | Authenticates version lookups on github.com, avoiding rate limits. |
| =RENOVATE_CONFIG_FILE=                          | Default for =--global-config=.                                   |
| =RENOVATE_PLATFORM=, =RENOVATE_ENDPOINT=        | For =@org/repo= elsewhere than github.com: GitLab, Forgejo...    |
| =RENOVATE_*=                                    | Forwarded to Renovate, like the ones above.                      |
| =RENOVATE_PREVIEW_RUNTIME=                      | Default for =--runtime=: =auto=, =podman= or =docker=.           |

Renovate's working directory, =/tmp/renovate= (its caches), lives in the =renovate-preview=
container volume between runs. =podman volume rm renovate-preview= resets it.

* Configuration

A repository is previewed with its own =renovate.json=. To try a change, edit it and
re-run; for a remote repository, clone it first.

=--global-config= adds a self-hosted (global) config. The repository config wins over it,
and command-line flags win over both.
[[file:docs/configuration.org][=docs/configuration.org=]] walks through the combinations.

* Good to know

- *No PR titles for a local repository.* Renovate's local platform stops after version
  lookups (it silently turns =--dry-run=full= into =lookup=, so renovate-preview refuses
  it), so branch names are known but PR titles are not. Against =@org/repo= the dry run
  is complete.
- *AGE and PENDING come from =minimumReleaseAge=.* AGE is the new version's age, empty when
  the registry gives no release date (many container registries don't). Renovate then
  can't check =minimumReleaseAge=, and by default holds the update back. PENDING is =yes=
  when the update itself waits for its checks, or names the newest version held back,
  like the Pending column of Renovate's PRs. =-o html= highlights both.
- *Only files known to git are seen.* Renovate lists files with =git ls-files=, so =git add=
  a new manifest before previewing it.
- *=--except= replaces what presets ignore.* A command-line =ignorePaths= replaces the
  configured one. =--except= restates Renovate's defaults and the =ignorePaths= in your
  =renovate.json=, but not those added by presets such as =config:best-practices=. See
  [[file:examples/preset-extends/][=examples/preset-extends=]].
- *=--only dir= means =dir= and =dir/**=.* Renovate itself would match only a file named =dir=.

* With renovate-pretty-log

[[https://gitlab.com/tanna.dev/renovate-pretty-log][renovate-pretty-log]] is for exploring a
Renovate debug log: a colourised printer, an HTML report, and a TUI with folding and
search. It reads the log of any Renovate run, including the ones your production instance
writes.

renovate-preview comes before the log. It runs Renovate for you, with the settings a preview
needs, and answers one question: which dependencies were found, and which updates are
available. When that answer is surprising, the log explains why:

#+begin_src sh
renovate-preview -o raw -w run.log                 # the same run, as Renovate's own log
renovate-pretty-log-tui -path run.log              # ... explored
renovate-pretty-log -path run.log -level warn      # ... or just its problems
renovate-preview -o raw | renovate-pretty-log -path /dev/stdin
#+end_src
