#+TITLE: Where Renovate's configuration comes from
#+OPTIONS: toc:nil num:nil

Renovate combines configuration from several places. Knowing which one wins explains
most surprises.

* The layers

From lowest to highest priority:

| 1. defaults          | Renovate's built-in defaults                                                     |
| 2. global config     | the self-hosted config: =--global-config= (or =RENOVATE_CONFIG_FILE=), then =RENOVATE_*= variables |
| 3. repository config | the repository's =renovate.json=                                                 |
| 4. command line      | Renovate flags: =--only=, =--except=, =--managers=, anything after =--=          |

When two layers set the same option, the higher one's value is used. Options that only
one layer sets are kept.

- *The repository config wins over the global one.* Most of its settings replace the global
  ones, but lists such as =packageRules= are appended to.
- *The command line wins.* Renovate's =forceCli= option, on by default, gives command-line
  flags priority over the repository config too. =RENOVATE_*= variables don't have it: they
  are global config.

* The demo repository

The scenarios below run on a small repository, in [[file:demo/repo/][=docs/demo/repo/=]]: two
identical manifests, and a config that ignores one of them and groups all updates.

=renovate.json=
#+begin_src json :tangle demo/repo/renovate.json :mkdirp yes
{
  "ignorePaths": ["a/**"],
  "packageRules": [{ "matchPackageNames": ["*"], "groupName": "demo group" }]
}
#+end_src

=a/kustomization.yaml=
#+begin_src yaml :tangle demo/repo/a/kustomization.yaml :mkdirp yes
helmCharts:
- name: cert-manager
  repo: https://charts.jetstack.io
  version: v1.20.2
#+end_src

=b/kustomization.yaml=
#+begin_src yaml :tangle demo/repo/b/kustomization.yaml :mkdirp yes
helmCharts:
- name: cert-manager
  repo: https://charts.jetstack.io
  version: v1.20.2
#+end_src

And a self-hosted (global) config, next to it in [[file:demo/][=docs/demo/=]]. Its
=branchPrefix= shows in the BRANCH column, so you can see when it applies.

=global.json=
#+begin_src json :tangle demo/global.json
{ "branchPrefix": "global/" }
#+end_src

* Scenarios

Run them from =docs/demo/repo=. Renovate only sees the files git tracks, so this works in
a checkout of this project.

** 1. The repository's own config

#+begin_src sh
renovate-preview
#+end_src

| FILE                   | BRANCH                |
| =b/kustomization.yaml= | =renovate/demo-group= |

=a/= is ignored and the update is grouped, both as the repository's config says.

** 2. A global config and the repository's: both apply, the repository's wins

#+begin_src sh
renovate-preview --global-config ../global.json
#+end_src

| FILE                   | BRANCH              |
| =b/kustomization.yaml= | =global/demo-group= |

Both apply: the prefix comes from the global config, and the ignored path and the grouping
from the repository's. Had the two set the same option, the repository's would have won:
with =global.json= also setting =ignorePaths: ["b/**"]=, =b/= is still scanned.

Use the self-hosted config of the Renovate instance that runs on your repository, and the
preview matches what that instance does.

** 3. Command-line flags win over every config

#+begin_src sh
renovate-preview -- --ignore-paths='b/**'
#+end_src

| FILE                   | BRANCH                |
| =a/kustomization.yaml= | =renovate/demo-group= |

The flag replaces the repository's =ignorePaths=: =a/= is back, =b/= is gone.
=RENOVATE_IGNORE_PATHS='["b/**"]'= instead changes nothing: it is global config, so the
repository's =ignorePaths= wins over it.

=--only=, =--except= and =--managers= are flags too, so they win over the repository config
the same way. That is why =--except= has to restate the =ignorePaths= it keeps (see the
README).

* Remote repositories

=renovate-preview @org/repo= uses the same layers, with the repository's config as it is
on its default branch. To try a change to it, clone the repository, edit its
=renovate.json=, and preview the clone. The one thing a remote preview adds is PR titles:
Renovate's local platform stops before computing them.
